# JohnnyWrt 独立首页与向导

用户已确认效果图并于 2026-10-28 明确要求开始实现、预检并用 GitHub 发布。旧 VPS 发布的删除已取消，由用户自行处理。此文将已确认的会话需求固化，不另设重复审批。

## 目标与边界
- 完全移除 iStore、QuickStart 及其首页/向导依赖，使用原生 LuCI、ubus/UCI。
- 首页沿用 Aurora 白色卡片布局：CPU、内存、存储、运行时间、网络流量与接口；MeowX 和 ZeroTier 为主要服务卡片。
- MeowX 使用官方 Logo；读取已登录账户头像/昵称及订阅额度、剩余、到期、更新时间；缺失数据明确未知。当前速率与订阅额度分开。提供启停、重载、重启、打开面板、账户刷新、订阅切换与设置入口。停用/重启须确认，失败显示错误，禁止重复提交。
- ZeroTier 使用官方 Logo；服务运行、节点在线、授权、IP、内网路由独立呈现。服务页面添加设置向导，保留配置/接口信息。输入16位十六进制网络ID→提示“请自行打开 ZeroTier 授权面板，授权此设备。”→自动轮询检查；不提供授权面板链接，不依赖官方 Central，支持第三方控制器。
- ZeroTier 默认检查两地内网互访所需的本地网段、转发和接收路由，自动读取地址。已有成员身份/网络/路由不得清除或覆盖。只有实际授权成功才跳过授权步骤。收到路由不等于端到端互通；网关可达与所有内网设备互通分别表述。
- 独立网络向导：主路由/旁路由→网口→地址/DNS→变更预览→原生确认与自动回滚。旁路由自动获取或静态管理地址、默认DHCP服务关闭；主路由明确WAN/LAN分离，WAN支持DHCP/静态/PPPoE，LAN地址及DHCP。不支持在同一物理端口上隐式创建单臂路由；复杂VLAN配置进入原生网络页。
- 所有数据来自设备；站点地址、订阅、密码、身份、账号名不得写死在代码、公共镜像或测试日志中。无订阅/未授权/服务停止/接口错误均需可用页面。

## 方案
曾比较修改 QuickStart 去商店依赖与独立原生首页/向导，用户选择后者。采用小型 LuCI JS 页面与受限 rpcd ucode 服务；复用现有 MeowX API、原生网络配置确认机制和已测试的 ZeroTier 转发辅助脚本，不引入新的前端框架或后台守护进程。

## 发布约束
- 基于 Johnnnypro/JohnnyWrt 的 main 分支，ImmortalWrt稳定25.12.2与匹配内核，x86/64 EFI/GPT SquashFS，32MiB引导、1024MiB根，Docker=no。
- 保留 Aurora、MeowX、ZeroTier、离线面板/地理数据、SSH -z、在线升级集成和原有主机名保留逻辑。
- 保留配置升级维持网络、密码、SSH密钥、MeowX订阅/账户、ZeroTier身份；不能改写原始测试baseline隐藏差异。
- QuickStart存在的旧镜像仍等待原先的初始化条件；新镜像验证原生网络与无待提交配置。不得直接删除就绪门槛。
- 先运行针对输入、权限、状态和网络变更的回归，再在GitHub执行完整打包、UEFI启动、BIOS旧到新/新到新升级、真实SSH、ISO内嵌哈希检查。关键门槛不通过不发布。
- 最终文件在两台已授权路由器上仅执行哈希、分区布局、sysupgrade -T校验，不刷写或重启实机。

## 验收
菜单与页面实际可加载；未登录/只读权限不可执行修改；输入不能注入命令；网络更改须确认且未确认可回滚；MeowX失败不拖垮首页；ZeroTier未授权/无地址不误报完成；无iStore/QuickStart包或菜单；升级配置与身份保持；产物SHA256、manifest与源提交可追溯。
